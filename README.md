# Force and Motion — Modern HTML/CSS/JavaScript conversion

## Start locally
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in Chrome, or use VS Code Live Server.

## Included
- 15 converted WordPress pages with original exported content
- Original uploaded media library (372 files)
- Pyidaungsu font files
- Original Additional CSS retained in `css/style.css`
- New modern responsive design overrides in `css/modern.css`
- Shared responsive navigation in `js/main.js`

## Customization
- Edit `css/modern.css` first for modern visual changes.
- Edit `css/style.css` for retained WordPress CSS and legacy custom rules.
- Original images are under `assets/uploads/`.
- Pages are individual `.html` files in the project root.

## Notes
WordPress block/plugin styling may not be reproduced pixel-for-pixel without the original theme/plugin runtime. Review each page at desktop, tablet and mobile widths. Keep the WordPress site and backups until final verification.
