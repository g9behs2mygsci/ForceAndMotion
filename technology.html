01 - HTML, CSS, PHP, JavaScript

html - စာမျက်နှာအကြောင်းအရာနှင့် Heading၊ Link၊ Image စသည့် အစိတ်အပိုင်းများ၏ ဖွဲ့စည်းပုံကို သတ်မှတ်သည်။
css - အရောင်၊ Font Size၊ Spacing၊ Card Design၊ Mobile Menu နှင့် Responsive Layout များကို ပြင်ဆင်သည်။
php - Website ၏ Server-side လုပ်ဆောင်ချက်များကို အကောင်အထည်ဖော်ပေးသော Programming Language ဖြစ်သည်။ Website တွင် WordPress ၏ လုပ်ဆောင်ချက်များနှင့် Quiz Plugin ကို ဖန်တီးရာတွင် PHP ကို အသုံးပြုထားသည်။
JavaScript - Website ကို အပြန်အလှန်လုပ်ဆောင်နိုင်စေရန် (Interactive) အသုံးပြုသော Programming Language တစ်ခုဖြစ်သည်။ Website တွင် JavaScript ကို Quiz စနစ်၏ လုပ်ဆောင်ချက်များအတွက် အသုံးပြုထားသည်။
